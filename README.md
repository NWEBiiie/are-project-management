# ARE Project Management — Field Guide

Independent exam study aid. Original explanations with links to NCARB, AIA Contract Documents, and other primary sources.

## Contents
17 objectives with 76 expandable lessons, 20 AIA document guides, 63 clause/topic cards, 34 original practice prompts, and 69 source links.

The interface uses shortened objective labels. NCARB Guidelines control exam scope and reference editions. AIA coverage is an exam-focused study map, not a reproduction of every contract clause. Read the full applicable documents and amendments for exact duties. Sources checked October 14, 2026.

## Worked examples
Gantt schedule with interactive delays, dependency network, forward/backward pass tables, staffing load chart, fee calculator, progress curve, contract relationships, change-form selector, budget breakdown, approval timeline, and coordination diagrams. Every lesson includes a worked example and a self-check.

Expanded October 15, 2026. All teaching cases are original.

## Run
Open index.html. No installation, account, external fonts, or paid API is required. Progress is stored only in this browser. Use Export progress to move it between devices or back it up.

## GitHub Pages
Publish the main branch, / (root), under Settings → Pages. All asset links are relative, so repository Pages URLs work.

## Public content
This folder contains only the website and original study notes. It does not contain licensed manuals, contract PDFs, audio, credentials, or personal notes from other apps. Linked documents remain on their publishers’ sites. AIA and NCARB do not sponsor or endorse this independent guide.
